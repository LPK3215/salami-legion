# 游戏模式详解

> 这一篇专门解释「到底有几种玩法、每种怎么结束、有没有无尽模式、棋盘是不是都一样大」。
> 你玩的时候产生的疑问，答案基本都在这里。

---

## 0. 先回答几个最常被问到的疑问

| 你的疑问 | 准确答案 |
|---|---|
| 是不是一关一关打，达到人数就开下一关？ | **关卡挑战是**。但第 1 关的目标是 **15 人**，不是 5 人（5 是开局人数选项之一）。**无尽模式不是**，见下一行。 |
| 无尽模式是不是也有一层一层、过关了人数重来？ | **不是，而且刻意不是。** 无尽模式**没有「层」这个概念**：人数只增不减，每满 50 人只是暂停一次让你三选一，选完接着打同一场，绝不重置人数。 |
| 是不是**每一关**开始前都要选技能？ | **不是。** 技能在**这次挑战开始时选一次**，之后整轮都用它。关卡之间出现的是「三选一奖励」，如果里面出现技能卡，那是**解锁/升级**，不是重新选。 |
| 有没有能一直玩下去的无尽模式？ | **有。** 主菜单 →「**无尽挑战**」，没有关卡也没有层数，唯一的结局是被打光。 |
| 每关都有时间限制吗？超时会失败吗？ | **有关卡计时，但没有硬性时间上限，永远不会超时失败。** 时间只用来评星：越快星级越高。 |
| 达成目标就直接停止？ | 关卡挑战：**是**，达成目标立刻结算并弹出奖励，这是设计如此（一关一个明确小目标）。无尽挑战：**不停止**，只是暂停一下让你选奖励，选完继续打同一场。 |
| 棋盘是不是每关都一样大？ | **主线 13 关全部是固定的 3000×2200**（只有镜头缩放随人数变化）。**无尽模式**的棋盘会随你的规模**逐级扩大**（有上限）。 |
| 到底有几种模式？ | 主要 **2 种**：关卡挑战、无尽挑战。另有「关卡选择」不是独立模式，是选一个起点关卡开新一轮挑战。 |

---

## 1. 模式一：关卡挑战（主线）

**入口**：主菜单 →「关卡挑战」

### 玩法
一关一关推进，一共 **13 关**。

每一关有两类目标之一：

- **达到 N 人**：军团人数增长到目标值即过关
- **消灭所有敌军**：把所有敌对军团吃到 0 人即过关

### 达成即停止
只要目标达成，**立刻结算并停止**，弹出星级评价和三选一奖励。
这是「一关一个明确小目标」的设计，不是 bug。

### 计时器的作用
顶部中间有个计时器，它**只是用来评星**，不会因为超时失败：

| 星级 | 条件 |
|---|---|
| ★ | 通关即可 |
| ★★ | 通关时间 ≤ 该关「两星线」 |
| ★★★ | 通关时间 ≤ 该关「三星线」 |

星级会记录在存档里，可在「关卡选择」页看到。

### 失败条件
我方军团人数降到 **0**。此时本次挑战结束，但**金币、已解锁技能、已购皮肤等永久内容全部保留**。

### 棋盘尺寸
**13 关全部固定 3000×2200**，只有镜头缩放会随你的人数变化（人越多镜越远）。
所以地图边界永远在同样的位置，敌军的「贴墙逃跑」行为是可预判、可围堵的。

## 2. 模式二：无尽挑战（没有层，一场打到底）

**入口**：主菜单 →「无尽挑战」（按钮上会显示你的历史最高人数）

### 核心差异（和「关卡挑战」最大的三处不同）

1. **没有「层」，也没有终点。** 不存在「第 1 层目标 40 人、第二层重来」这种事。
   无尽模式就是**一整场连续对局**，你的人数是**累积的、只增不减**的。
2. **每满 50 人 = 一个里程碑。** 达到 50 / 100 / 150 / 200 …… 人时，对局**暂停**，
   弹出三选一奖励（技能 / 本局增益 / 金币），选完**回到同一场对局继续打**，人数一个都不会少。
3. **唯一的结局是被打光。** 我方人数归零 → 本局结束，结算「本局峰值人数」。

> 换句话说：里程碑只是「暂停发奖」，不是「过关重来」。越往后你的军团越大，
> 镜头越远、编队越大，滚雪球的手感是连续的。

### 敌军怎么变强（程序化，跟着你的人数走）

无尽模式**不按层数生成关卡**，而是每分钟对场上敌军做一次「难度对齐」：

| 项目 | 规则 | 说明 |
|---|---|---|
| 敌军支数 | `min(2 + ⌊峰值人数 / 45⌋, 7)` | 你越大人越多路敌人，最多 7 支 |
| 每支敌军目标人数 | `max(8 + 存活时间 × 0.28, 峰值人数 × 0.30~0.85)` | 按支数从弱到强排布，**始终略低于你**，保证一对一能吃掉 |
| 阵亡后 | 自动补充新敌军（在离你 900~1600 距离外登场） | 不会因为杀光就进入「空场」 |
| 敌军移动 / 好斗 / 反应 | `sp ≤ 1.25`、`ag ≤ 0.92`、`react ≥ 0.26` | 随你的规模增强，各有上限 |
| 中立小人目标量 | `160 + 峰值人数 × 1.1`（上限 460） | 棋盘上始终有粮可吃 |
| **棋盘尺寸** | `3200×2400` 起，每过一个里程碑加 `120×90`，上限 `4800×3600` | 随规模扩大，新区域会补装饰与中立小人 |

关键点：**敌军始终比你弱一点**，所以「吃掉一支」永远是可行的；
压力来自**同时面对多支**，以及**就算你原地不动，敌军也会随时间慢慢加压**（上式里的 `8 + 存活时间 × 0.28`）。

### 难度曲线参考

| 阶段 | 人数 | 体验 |
|---|---|---|
| 开局 ~ 50 人 | 2 ~ 3 支敌军 | 热身，主要是在抢中立小人 |
| 50 ~ 150 人 | 3 ~ 5 支敌军 | 开始需要规划路线，避免被夹击 |
| 150 ~ 300 人 | 5 ~ 7 支敌军 | **真正的墙**：敌军单支已经接近你的一半 |
| 300 人以上 | 7 支敌军满编 | 高手区间，一次失误就掉一大块 |

### 记录
你的**历史最高人数**会永久保存，并显示在主菜单的「无尽挑战」按钮上；
成就里也有两个专门为无尽模式设置的成就（单局 100 人、单局 250 人）。

## 3. 「关卡选择」是什么？

主菜单 →「关卡选择」

它**不是一个独立模式**，而是一个**跳关入口**：

- 展示全部 13 关（未解锁的显示为灰色），以及你在每关拿到的星级
- 点任意已解锁的关卡，就**以该关为起点**开始一次新的关卡挑战

⚠️ 注意：直接从后面的关卡开始，你**没有任何累积增益**（增益只在一次挑战内部积累）。
所以从第 12 关直接开打会非常难，更适合挑战自己或回头看某一关。

## 4. 一次「挑战」的完整生命周期

两种模式都是「**出征准备选一次开局人数与技能，中途靠三选一奖励变强**」，
但推进方式完全不同：

```
主菜单
  ├─ 关卡挑战 → 出征准备 → 第 1 关
  │                     ↓
  │            达成目标 → 星级结算 + 三选一
  │                     ↓
  │              进入下一关（人数从头开始，增益累积）
  │                     ↓
  │            …… 循环，直到通关第 13 关或被打光
  │
  └─ 无尽挑战 → 出征准备 → 同一场对局
                        ↓
             人数一路上涨（不重置）
                        ↓
        每满 50 人 → 暂停 → 三选一 → 回到同一场继续
                        ↓
             …… 循环，直到被打光（唯一结局）
```

**关键点**：

- 技能只在**开始这次挑战时选一次**，中途不会让你重选（奖励里能拿到技能升级/解锁）。
- **本局增益**（如「行军加速 +7%」「遍地人潮 +25%」「先锋增援 +2 人」）在**整轮挑战内一直累积**，
  你可以在对局左下角看到当前所有增益标签。
- 中途可以点右上角 `❚❚` 暂停；无尽模式里那颗按钮是「**重开一局**」（因为不存在「本关」）。
- 失败后金币保留，重新开始就是一轮新的挑战。
- 无尽模式的里程碑奖励**不会出现「解锁开局人数」卡**（中途用不上），
  技能卡的权重会被调高，让每次里程碑更接近「选一个技能」的抉择。

## 5. 三种入口对比一览

| | 关卡挑战 | 无尽挑战 | 关卡选择 |
|---|---|---|---|
| 本质 | 主线推进 | 一场连续对局 | 跳关入口 |
| 关卡 / 层数 | 13 关 | **没有层，也没有关卡** | — |
| 推进方式 | 达成目标 → 下一关，人数重头开始 | 人数只增不减，每满 50 人暂停三选一 | — |
| 是否结束 | 通关第 13 关即结束 | 只有被打光才结束 | — |
| 棋盘 | 固定 3000×2200 | 随规模逐级扩大（3200×2400 → 4800×3600） | 同主线 |
| 记录 | 每关星级 | 单局最高人数 | 仅查看 |
| 增益累积 | 有 | 有 | 有（从所选关开始） |
| 解锁条件 | 初始可用 | 初始可用 | 逐步解锁关卡 |
